## 8. 本次可宣称的功能范围

- 同一工作台提供云端个人上传、学习参考检索、本机目录索引、原文回查、确定性工具与既有 V11 复核流程。
- PDF/DOCX/TXT/MD/CSV/JSON 在导入或扫描阶段解析并建立索引；本机目录依靠显式根目录、loopback/Host/Origin 检查及 Vercel 禁用保护。没有自动 OCR 或全盘后台监控。
- 学习参考、云端个人资料、本机目录采用页级词项检索与别名/正文门控。受审制度库可按配置使用已有 BGE 语义候选和 RRF；不把所有入口描述为已运行完整向量与神经重排链路。
- 排期生成的是待复核的候选发送日，排除周末及已提供日历中的节假日。2026 年中国放假调休日历有明确来源和年度覆盖，不自动外推未来年份、其他国家、交易所或机构特殊日历。
- 反馈改进属于候选规则、回放和人工审批的工程闭环；没有训练基础模型或自主修改模型权重。
- 国内常驻服务、托管知识库或海外其他云平台是部署选项，未因方案说明而成为本次已部署成果。
