# 金枢｜产品需求、功能规格与验收 V5

## 产品目标与来源

面向金融产品中后台资料查询、发行支持与核查任务，将“查依据—执行工具—生成草稿—反馈复盘”放到同一个工作台。需求来源是既有实习方法、用户材料与参考工程，部门角色是设计假设，不代表完成真实企业访谈或采购验收。

价值假设是减少切换工具和查找依据的成本，后续需要真实任务验证，不预填效率提升比例。

## 用户任务与优先级

|角色假设|任务|一期输出|
|---|---|---|
|产品与发行支持|对标、日期、周报和材料|可调参数、结果表、Word草稿|
|风险产品与运营|字段时点、邮件和特征核查|可用字段、匹配状态、禁用候选|
|知识使用者|学习概念、查业务依据|有来源的回答和完整提取文本|
|资料维护者|新增资料和复核范围|上传、敏感标记、启停和删除|

P0：问答来源、上传解析、active过滤、计算工具和失败提示。P1：Trace、反馈、回放与导出。P2：模型增强、偏好和体验表单。非目标：真实资金、客户冻结、外部发信、无人审核的策略上线、企业多人共享和集群高可用。

## 对话规格

输入1—2000字，可手选11类工作流。自动路径由术语和索引结果选择；不确定则澄清。短追问结合上次问题，原话与改写分别保存。输出包括内容、来源、页码、片段ID、模式、路由、top-k、执行步骤和Trace。

默认输出必须标记词项检索整理；调用可选模型后标记待复核草稿。无相关证据不编造规定。来源面板能够逐页查看全部提取文字，不将回答长度限制误作原文截断。

## 文档状态规格

选择文件与工作流/敏感标记 → 原生解析、哈希和切片 → pending_review → 本地确认 → active。停用进入archived，删除移除本地副本。

40MB/文件、1500页、25000现成片段的限制明确提示。PDF无文字不假装解析；不默认OCR。切片保留doc_id、page、version、字符位置。重复文件不重复入库。

本地启用只影响当前浏览器，不冒充两人审核。浏览器存储不是共享知识平台，完整部署才提供相应服务器流程。

## 工具规格

理财对标：六维可比池与共同观察区间；收益、回撤、中位数等。
发行排期：拟日期、期限、频率、批次与模拟营业日历；同时显示原日期和调整结果。
周报：编码按字符串、缺失保留、重复主键和异常数字报错。
材料：根据工具结果生成可编辑Word草稿。
开户：判断字段在决策节点是否已经生成。
案件：找到记录、多个匹配、没有找到分别展示；发送不等于送达。
策略：仅允许已登记特征和事件，结果保持disabled。
三表：核对资产负债、现金变动与期末现金。

数字由函数计算，不由模型猜；JS浮点演示不是资金账务。

## 反馈状态规格

用户反馈关联Trace，选择intent/retrieval/generation/knowledge_gap。知识缺口形成补资料待办。其他类别生成top-k最多8、受限检索词候选，重跑历史查询比较来源保留；确认后本地生效。下一次Trace必须包含候选ID与参数。回滚停止候选并恢复基线5。

这是可执行的简化Loop，不是LLM自主训练或真实多用户灰度。完整质量还需要答案标签与对照任务。

## 验收用例

|检查|预期|
|---|---|
|银行四职能|四项及相关出处完整显示|
|TXT上传—启用—刷新—再问|已提交内容仍能找到|
|Word导出和重新上传|有效DOCX正文结构、可解析|
|原生PDF|取得文字与页码，无需OCR|
|115页分页JSON|末页内容不丢失|
|8类工具|真实函数执行，得到表格|
|日期与周报|非法日期拒绝，编码前导零及缺失保留|
|反馈候选|回放后启用影响下一次top-k|
|回滚|候选停止，不改事实或计算|
|移动端|页面不水平溢出，导航可滚动|

以上已通过程序与Chromium检查，证据见evidence/v5。16题是自编开发回归，不是独立金融准确率。Vercel线上部署、真实模型函数试用、真人效果和K8s容量测试没有被这些检查证明。

## 迭代建议

先补真实提问与独立标签，改善复杂表格和跨页父块；再评估合适模型的质量、延迟、成本；最后依据共享和访问需求升级服务。实际用户指标应包含完成、独立正确性、耗时、返工，而非只报模型调用成功。
