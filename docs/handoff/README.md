## 公开版不包含什么

本仓库是 **public**。为避免泄露个人信息与版权风险，此次**没有**上传原始 11MB ZIP、含联系方式/照片的个人简历 PDF/DOCX、课程作者原始压缩包、数据库备份、账号信息、模型密钥或公司业务资料。这些本就不应进入公开 GitHub 历史。

当前可编辑的**项目简历文字、技术面试问题和源码**已在仓库对应文件中；如果将来要修改完整个人简历，请在新的 Chat **另行上传私有简历**，不要让助手把它提交到公开代码仓库。GitHub 的文件可以在浏览器直接打开，亦可通过 Raw 阅读。

> 优先区分：原文枢参考架构、金枢已经上线的功能、本轮隔离测试、真实在线 API 验证、尚未实现的路线图。引用过去的数字必须保留其测试口径。
