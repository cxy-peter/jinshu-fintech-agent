# 产品岗位项目表述

**金枢｜金融产品中后台智能助手（Agent）**　2026.09—至今　个人项目

- **场景拆解与方案设计：**结合理财与风控实习中的资料查询、发行支持及核查需求，梳理11类业务工作流，明确用户任务、输入输出与人工复核点，形成需求清单、业务流程及功能验收标准。
- **原型搭建与能力验证：**复用既有Python方法，将理财对标、排期及报表处理封装为Skill；搭建交互工作台，串联资料上传、切片检索、意图路由、多轮追问与来源展示，支持核对结果及材料草稿生成。
- **反馈复盘与迭代：**按路由、检索、生成及知识缺口梳理问题，组织反馈、候选策略、历史回放与人工确认流程；补充分级降级及回滚机制，沉淀操作指引与验收用例，完成核心交互验证。

产品与数据：需求梳理、BRD/PRD、业务流程、功能规格、原型验证与验收；Python、SQL、Excel。

AI应用：LLM、RAG、Agent、Prompt；意图路由、多轮对话、可执行Skill、来源追溯与效果评估。

简历统一为一个个人项目，不拆成两个项目。技术追问仍须说明实际实现范围、参考工程和AI辅助；不改写为企业正式上线或学校委托项目，不列未使用的原型工具。
