# V10.1：恢复个人资料，区分存储位置

V10 的默认页面只检索审核后的共享库，没有读取 V7 当前浏览器的个人资料。线上验收留下的合成排期材料又被当作普通已审核材料召回，因此回答与用户实际上传的研究资料脱节。

本次保留 V10 权限、版本、原文哈希、独立审核、Memory、Loop、灰度和迟到请求保护，恢复一条明确标记为个人参考的本地资料链路。个人资料不会自动变成共享制度。

## 使用

1. 首页先显示提问框，额外检索设置、临时资料及运营账号在其下方。Enter 发送，Shift+Enter 换行；中文输入法确认字词不发送。
2. 在“资料与上传”恢复**当前域名**的 V7 `jinshu-lite-v5` 工作区，或导入个人 JSON 包。旧库只读，新库写入 `jinshu-personal-v1`。其他域名的浏览器数据必须先从旧页面导出，网页不能跨域读取。
3. 可以先“检索本机原文”，无需模型密钥。点击结果打开全文页码。聊天只发送至多六个命中片段，每片至多1,200字；完整包留在本机。发送前仍要求内容授权；选择保存对话时，回答及引用进入该运行环境的持久化库。
4. 合成验收材料默认不参与召回；需要显式勾选示例。没有匹配正文时返回知识缺口，不能用常见词的零散匹配替代。

## 本地运行

在已有 Python 环境安装 `requirements.txt`。如果要从原文件重新制作资料包，另安装本地依赖 `PyMuPDF==1.26.4`（云端不增加该依赖）：

```powershell
python scripts/build_personal_pack.py "本机资料目录" --out private_corpus/recovered-personal-materials.json
python scripts/run_personal.py
```

打开 `http://127.0.0.1:8768/`。启动器强制 SQLite，将记录保存在 `workspace/personal-v101`；原件不改动。需要模型时，把 `DEEPSEEK_API_KEY` 放在被 Git 忽略的根目录 `.env`，重启。没有密钥仍可本地检索和运行八类业务工具。云端敏感环境变量不能读回，不宣称自动复制成功。

`/api/local-materials` 只读取管理员预设路径，只允许 loopback 客户端与 localhost Host，并在 Vercel 上强制关闭。没有任意文件路径参数。私人语料目录被 Git 和发布打包器排除。

## 检索边界

- 原样复用 V7 中文 BM25、标题加权、目录页降权、650字分页切片与60字重叠；Web Worker 建索引，保持输入区响应。
- 个人资料保留真实 PDF 页码，可从引用返回原文；没有将切片序号伪称为条款号。
- 个人检索是词项检索，不声称这条本地链路已经使用 BGE 或 Milvus。共享审核库原有 BGE 512维、RRF 和可选 DeepSeek 重排继续保留。
- PDF 为原生文字抽取；没有OCR，也不保证表格、公式排版准确。历史研报不能自动当成现行制度。
- 旧库待审/归档状态不会被升级；这次原文件导入属于用户个人参考，不授予共享审核权限。
- 页数、切片数只反映规模，不代表回答准确率。“发行排期”正式SOP若原文未找到，不能宣称已经恢复。

## 数据在哪里

| 数据 | 存储 | 本次处理 |
|---|---|---|
| 原始研究PDF等 | 用户本机原目录 | 保留，按内容哈希去重抽取 |
| 个人完整资料包 | `private_corpus` 和当前浏览器 IndexedDB | 本地重建，可导入/导出；不上传公开仓库 |
| 共享已审核资料、已保存对话、反馈与策略 | 云端 MongoDB / 本地 SQLite | 沿用现有治理与持久化，不自动包含全部旧上传材料 |
| 迁移前业务快照 | 旧私有 Blob 及本地备份 | 保留，不删除 |
| 程序、依赖、静态产物、历史部署 | Vercel Deployment Storage | 与上述业务数据不同；不能把用量数字当作材料大小 |

V4/V6 的历史文档明确写过“90份私人资料/19,032片不随公共站点发布”。不能推断这90份原件曾全部存放在Vercel。此次本机恢复数量与旧统计不同，也不能据此说旧资料已经全部找齐。

Vercel 部署存储包含构建输出和函数包，迁移 MongoDB 不会自动删除历史部署；历史计量也不等于当前文件总量。[官方说明](https://vercel.com/docs/deployment-storage)。本轮账户页面被保存的浏览器访问限制阻止，未读取用户的8.xGB明细，未执行任何清理。删除前仍需实际清单、生产别名和回滚保留检查。

## 可选服务

MongoDB Atlas 免费版的512MB是数据库配额，不是运行 Redis、Milvus 或 pi 的主机；不能直接把这些进程“搬进MongoDB”。目前仍是可选服务适配器，未声明已部署。没有 Docker/WSL 的电脑可以先用 SQLite、浏览器索引与现有 CPU BGE，避免新服务器和常驻服务。将来部署外部服务后再配置各自地址并做真实连通验收。

## 验证范围

本地单元测试覆盖个人片段页码、外发同意、禁止伪装共享来源、合成材料默认排除、Vercel禁用本地资料路由与DNS重绑定Host拒绝。浏览器验收覆盖原文检索、原文打开、首屏输入位置、Enter/Shift+Enter。GitHub CI 继续运行原有共享审核、历史恢复、工具导出、失败降级和移动端检查。模型协议测试明确使用测试响应，不计为真实 DeepSeek 调用。
