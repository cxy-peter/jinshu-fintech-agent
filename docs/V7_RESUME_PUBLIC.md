# 金枢｜金融中后台 Agent：知识、工具与反馈迭代

个人项目｜产品与方案设计、AI辅助实现｜2026.09—至今

## 单项目投递版

- **业务与产品方案：** 围绕资料查询、理财对标、发行支持及核查需求拆解11类工作流，明确模型、检索、固定计算与人工复核的边界，形成PRD、原型和验收用例；将结果按“要点—依据—下一步”分层展示。
- **可信知识与业务工具：** 适配来源版本校验及混合检索服务方案，交付可回查页码与原文的轻量工作台；封装8类确定性工具，支持数据质检、排期和材料导出，并以输入/结果版本约束复核及交付。
- **反馈与策略治理：** 将检索问题转为有界候选，按同批实际问答比较基线与候选；绑定配置、资料、样本及评测器版本，发布前重验收、人工确认后生效，支持恢复前版；资料缺口与路由问题分类转待办。
- **评测与迭代：** 保留500项开发验收，针对千分位、编码和缺失数据问题修复工具合同，本地通过项由485增至489；补充受控模型、异步旧结果、任务确认与发布回滚测试，不将离线检查等同模型准确率。

## 与旅游项目的分工

本项目强调业务规则、数据交付和变更治理；Visit China强调服务意图、对话体验与运营反馈。单独使用时保留问题—方案—验证的完整叙事，不依赖面试官读另一项目。

## 证据边界

个人AI辅助项目；不是从零手写全部原框架。网页默认原文检索整理；完整服务混合检索与真实模型验收状态分开。500项为同一标签的本地开发验收，11项问答问题仍保留；没有真实用户提效、企业审批或线上A/B成绩。
